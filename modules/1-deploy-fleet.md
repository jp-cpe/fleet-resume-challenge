# 1. Deploy Fleet

Deploy a Fleet server you own end-to-end.

## Goal
A working Fleet instance you own and can administer end-to-end.

## Resources
- [Step-by-step: Deploy Fleet](../guides/deploy-fleet.md)
- [Deploy Fleet](https://fleetdm.com/docs/deploy/deploy-fleet)
- [Deploy Fleet with Docker Compose](https://fleetdm.com/guides/deploy-fleet-on-docker-compose)
- [Try Fleet (free Premium trial)](https://fleetdm.com/login#)
- [License key configuration](https://fleetdm.com/docs/configuration/fleet-server-configuration#license-key)

## Tasks
- [ ] Deploy a Fleet server using the hosting method of your choice (Docker/local is $0; Render is an optional ~$65/mo convenience)
- [ ] Add a **free Fleet Premium trial** license key to unlock the Premium-flagged modules (valid for 30 days)
- [ ] Complete first-run setup and sign in to the UI

## Done when
- [ ] Fleet UI loads at a stable URL you own, the Hosts page is reachable, and My account shows a license expiration date
