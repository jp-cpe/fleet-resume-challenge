# 15. Automating Fleet (API & fleetctl)

Fleet's two non-UI surfaces: the `fleetctl` CLI and the REST API.

## Goal
Fluency driving Fleet without the UI — running live queries and pulling data from both `fleetctl` and the REST API.

## Resources
- [Step-by-step: fleetctl and the REST API](../guides/automating-fleet.md)
- [fleetctl](https://fleetdm.com/guides/fleetctl)
- [Fleet's Postman collection](https://www.postman.com/fleetdm/workspace/fleet/collection/18010889-c5604fe6-7f6c-44bf-a60c-46650d358dde)

## Tasks
- [ ] Run a live query and pull host/query data using `fleetctl`
- [ ] Make the core Fleet API calls with curl and your token
- [ ] Reproduce those calls in Postman against your sandbox

## Done when
- [ ] You can run a live query from the CLI, and the core API calls succeed via both curl and Postman
