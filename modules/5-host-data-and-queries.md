# 5. Host data & queries

Fleet continuously collects data from every host, and lets you ask your own questions on top of it.

## Goal
Comfort navigating the host data Fleet collects automatically (host vitals), plus running live, scheduled, and GitOps-managed osquery reports.

## Resources
- [Step-by-step: Host vitals and reports](../guides/host-data-and-queries.md)
- [Run a live report](https://fleetdm.com/guides/get-current-telemetry-from-your-devices-with-live-queries#basic-article)

## Tasks
- [ ] Explore host vitals on a Host details page and trigger a refetch
- [ ] Run a live osquery report
- [ ] Add a scheduled query to your GitOps repo and confirm it collects data
- [ ] Add a custom query to your GitOps repo

## Done when
- [ ] You can explain where host vitals come from, and you've run 1 live query, added 1 scheduled query via GitOps, and added 1 custom query via GitOps
