# 5. Host data & queries

Fleet continuously collects data from every host, and lets you ask your own questions on top of it.

## Goal
Comfort navigating the host data Fleet collects automatically (host vitals), plus running live, and scheduled reports. Manage it all with GitOps.

## Resources
- [Step-by-step: Host vitals and reports](../guides/host-data-and-queries.md)

## Tasks
- [ ] Explore host vitals on a Host details page and trigger a refetch from an online host
- [ ] Add a scheduled report to your GitOps repo and confirm it collects data
- [ ] Run a live osquery report

## Done when
- [ ] You can explain where host vitals come from, you've added 1 scheduled report via GitOps, and you've run 1 live report
