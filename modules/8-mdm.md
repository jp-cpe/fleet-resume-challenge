# 8. MDM

Deliver OS settings and issue commands to your hosts using MDM.

> Basic MDM enrollment is free; **lock and wipe commands** require Fleet Premium (free with the trial from [Module 1](1-deploy-fleet.md)).

## Goal
MDM configured for your sandbox, a configuration profile applied to at least one host, and at least one MDM command issued and acknowledged.

## Resources
- [Step-by-step: MDM setup and commands](../guides/mdm.md)
- [MDM macOS setup](https://fleetdm.com/docs/using-fleet/mdm-macos-setup)
- [MDM Windows setup](https://fleetdm.com/docs/using-fleet/mdm-windows-setup)

## Tasks
- [ ] Complete MDM setup: APNs certificate, ABM, ADE, and SCEP configuration
- [ ] Turn MDM on for at least one device
- [ ] Issue at least one MDM command using the REST API (lock, wipe, or restart)

## Done when

- [ ] At least one MDM command has been issued and acknowledged
