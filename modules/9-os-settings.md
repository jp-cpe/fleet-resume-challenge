# 9. OS settings

Enforce OS settings on your hosts with configuration profiles (macOS `.mobileconfig`, Windows CSPs, and Android `.json`).

## Goal
Custom OS settings deployed and confirmed on macOS and Windows hosts via Fleet.

## Resources
- [Step-by-step: Custom OS settings](../guides/os-settings.md)
- [Configuration profiles (custom OS settings)](https://fleetdm.com/guides/custom-os-settings)

## Tasks
- [ ] Deploy a custom macOS configuration profile (`.mobileconfig`) via GitOps
- [ ] Deploy a Windows CSP via GitOps
- [ ] Confirm profiles are applied on each target host

## Done when
- [ ] A custom configuration profile is deployed and applied on at least one macOS host
- [ ] A custom OS setting is deployed and applied on at least one Windows host
