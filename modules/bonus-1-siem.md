# Bonus 1. SIEM | logging

Ship logs to a SIEM.

## Goal
Query, policy, and script results from Fleet flowing into a SIEM where you can search them and build a dashboard.

## Resources
- [Step-by-step: Ship logs to a SIEM](../guides/siem.md)

## Tasks
- [ ] Stand up a free-tier SIEM (Elastic, Splunk Free, or Grafana Cloud + Loki)
- [ ] Configure Fleet's result and status log destinations
- [ ] Schedule a query and confirm results are searchable in the SIEM
- [ ] Build one dashboard panel

## Done when
- [ ] Scheduled query results land in your SIEM and a dashboard panel renders them
