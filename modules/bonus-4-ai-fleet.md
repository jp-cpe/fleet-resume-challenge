# Bonus 4. AI + Fleet

Use AI to manage Fleet.

## Goal
At least one AI-assisted osquery query or GitOps config validated against official docs and deployed to your Fleet instance.

## Resources
- [Step-by-step: AI + Fleet](../guides/ai-fleet.md)

- [ ] Use AI (e.g., Claude) to write an osquery query, then validate the output against Fleet's docs before deploying it
- [ ] Use AI to generate a GitOps config snippet and verify it works in your sandbox
- [ ] Demonstrate at least one practical AI + Fleet workflow end-to-end

## Done when
- [ ] At least one AI-assisted query or GitOps config has been validated against official docs and deployed to your Fleet instance
